# Changelog

## v1.1.0 — 13 November 2026

- Added four-file YAML configuration with shared parameters, explicit experiment
  differences, a single local paths file and the two original preprocessing rules.
- Added a unified prepare/run/evaluate CLI with explicit execution, seed selection,
  path preflight, separate validation/test outputs and overwrite protection.
- Added 11 portable-interface tests; retained both original scientific snapshots
  and synthetic implementation checks.
- Documented matched-input measured baselines, enriched auxiliary supervision and
  a bounded 13-entry real-data smoke test.
- Removed redundant per-seed configurations, nested archives and obsolete helpers.
- Updated citation/provenance and integrity metadata; no model or loss changes.

## v1.0.0 — 28 October 2026

Original frozen principal/control code, configurations and synthetic checks.
The original tag, release asset and Zenodo DOI remain available unchanged.
