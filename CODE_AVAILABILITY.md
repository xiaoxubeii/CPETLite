# Code and data availability

The CPETLite code release is available at https://github.com/xiaoxubeii/CPETLite, version v1.0.0.
The exact archived release identifier will be added after Zenodo confirms publication.
No DOI is claimed by this staging metadata.

This public repository contains code/configuration and synthetic tests only.
Clinical records, teacher-generated targets, model weights, examination-level
predictions, aggregate source workbooks/CSVs and private manuscripts are excluded.
Their access conditions are governed separately by the data-holding institutions.
Possession of this code grants no clinical-data access or medical-use approval.
