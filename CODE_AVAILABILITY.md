# Code and data availability

The portable code release is CPETLite v1.1.0 under the MIT licence:
<https://github.com/xiaoxubeii/CPETLite/releases/tag/v1.1.0>.
Use this fixed tag and the code ZIP/checksum attached to it for this version.
The moving main branch is not an immutable archival reference.

The earlier v1.0.0 archive remains at
<https://doi.org/10.5281/zenodo.23734812> (archived commit
`f0c0c354effed1121cc91f88aad28801549e2a0b`). That DOI identifies v1.0.0,
not v1.1.0. A separate v1.1.0 archival DOI has not been verified in this source.

This public repository contains code/configuration, documentation and synthetic
tests. Clinical records, teacher-generated supervision, model weights,
examination-level predictions, aggregate clinical source workbooks/CSVs and
private manuscripts are excluded. Aggregate reporting material is supplied
separately in the paper's Supplementary Material 2. Clinical access is governed
by the data-holding institutions; code availability grants no data access.

This framework supports offline reconstruction research and has not been
validated as a medical device or as a real wearable-device deployment.
